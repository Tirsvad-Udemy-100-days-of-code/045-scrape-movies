# scrape-movies wiki

Day 45 of Udemy's "100 Days of Code: The Complete Python Pro Bootcamp" is about web scraping with Requests and BeautifulSoup. This repository reproduces every lecture step as tested Python code. This wiki shows each step with a screenshot and explains what we gained from it.

## For whom

- **Coursists:** readable, runnable code that keeps the assignment's ideas; compare it with your own solution.
- **Visitors:** a small example with tests and only two runtime dependencies, `requests` and `beautifulsoup4`.

The code and the documents are in the [repository](https://git.tirsystem.com/Tirsvad-Udemy-100-days-of-code/045-scrape-movies).
